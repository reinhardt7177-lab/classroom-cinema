# 교실극장

초등 1~6학년 감상 수업을 위한 영화·애니메이션·방송 드라마 143편을 담았습니다. 이 폴더의 `index.html`을 Edge나 Chrome에서 열면 별도 설치 없이 사용할 수 있습니다.

1. 추천 학년과 주제를 고르거나 제목, 활동 이름 또는 방송사(KBS·EBS)를 검색합니다.
2. 작품을 눌러 줄거리, 교육 포인트, 2022 개정 교육과정 성취기준을 확인합니다.
3. 상세 화면에서 작품별 핵심 가치와 학생용 A4 미리보기를 확인하고 **학습지 PDF 다운로드**를 누릅니다. 미리보기를 눌러 원본 PDF를 크게 볼 수 있습니다.
4. 질문을 바꿀 때는 **미리 보고 편집하기**를 선택합니다. 편집본은 브라우저에 저장되며 인쇄 화면에서 PDF로 저장할 수 있습니다.

작품 이미지와 기본 학습지는 이 폴더에 포함되어 있습니다. 방송 영상은 모음·편집·분할 여부를 상세 화면에서 확인할 수 있습니다. 픽사 작품 소개 링크는 제작사의 안내 페이지로 연결됩니다. 공식 시청 페이지를 열 때 인터넷이 필요합니다. 교실에서 상영하기 전에 계정 재생과 자막, 이용 조건을 확인하세요.

## 학습지 갱신

`catalog.js`에서 학습 목표는 작품 항목의 `goal`, 활동 질문·핵심 가치·응답 형식은 `worksheetActivities`에서 편집합니다. Python 환경에 `reportlab`과 `pypdfium2`를 설치하고 프로젝트 폴더에서 `python scripts/build_worksheets.py`를 실행하면 PDF, 미리보기, 오프라인 다운로드 파일이 함께 갱신됩니다. 기본 글꼴은 Windows의 맑은 고딕입니다. 다른 환경에서는 `--font`, `--bold-font`에 한글 TrueType 글꼴 경로를 지정할 수 있습니다.
